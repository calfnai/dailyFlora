Build tooling

Vite, TypeScript and their transitive open-source packages support development and production builds under their respective licenses. The repository lockfile records exact installed versions.

Fonts and icons

The public interface currently uses operating-system font stacks, including Iowan Old Style, Baskerville, Times New Roman, Inter where installed, and platform UI sans-serif fonts. No webfont file is intentionally downloaded by the current public pages.

Interface icons used in the main viewer are original inline SVG paths assembled for DailyFlora’s controls; no separate public icon-font package is loaded.

References and attributed materials

Botanical, floral-arrangement and interface references used during private research remain subject to their original authors’ and rights holders’ terms. They are not automatically licensed for public redistribution. Any third-party asset added to a public release must be reviewed for its source, permission and required attribution before publication.

The special NGC 2787 image and the audio/reference material stored in the repository require a release-by-release provenance check before any broader commercial distribution. This credits page does not transfer or replace the original rights attached to those files.

Corrections and attribution requests

If an attribution is incomplete or you believe a material has been used incorrectly, contact find@calfn.com with the relevant page, asset and source information.
