Privacy Policy

This policy describes what the current DailyFlora Web experience actually does. It will be updated before cloud accounts, analytics, payments or server uploads are introduced.

1. Information handled

DailyFlora can handle a display name and email address entered into the local MVP account form; bouquet favorites; interface language, clock and tutorial preferences; date, seed and visual parameters; and a reference image you deliberately select. The current public site does not run a DailyFlora analytics service, advertising tracker, payment system or email-notification service.

2. Browser-local data

The current name, email, favorites, idle-clock settings, interface language and tutorial choices are stored in localStorage on your device. They are not synchronized to Supabase or another DailyFlora account server. The signup password is neither stored nor transmitted. Clearing site data removes these browser-local records.

Favorites store bouquet metadata such as date, seed, theme, flower-plan name and save time. They do not store a server-side copy of the rendered 3D scene.

3. Reference images and private bouquet previews

When you choose a reference image, JavaScript FileReader reads it into the current browser tab. A small temporary Canvas sample is used to calculate an average colour and choose a theme direction. The selected image is displayed locally for the current session. The current implementation does not upload that image to a DailyFlora server and does not persist the image file in localStorage.

A generated preview may save bouquet metadata as a favorite if you choose to save it, but the source image itself is not included in that favorite record.

4. Camera and gesture control

DailyFlora requests camera permission only after you actively choose to enable gesture control and then start the camera. You can stop it at any time. MediaPipe Tasks Vision analyses live frames in the browser to estimate hand landmarks and gestures.

  • Camera audio is not requested.
  • Live video frames and hand images are not uploaded by DailyFlora.
  • DailyFlora does not save video, screenshots or hand images.
  • When control is stopped or the page unloads, active camera tracks are stopped.
  • Your browser and operating system still control the permission indicator and permission history.

5. Sharing and public information

A shared URL may reveal its included date, seed, theme or quality parameters to anyone who receives it. Current device-local account details and favorites are not automatically placed into share links. Future public profiles or user publishing are not active.

6. Third-party technology

The experience uses Three.js for 3D rendering and MediaPipe Tasks Vision for browser-based hand recognition. It may be hosted through GitHub Pages, Vercel or another configured static hosting provider, which may process ordinary network information such as IP address, request time and user-agent information under its own infrastructure policies. DailyFlora does not currently set a marketing cookie or add a first-party analytics SDK.

7. Data deletion and retention

You can delete local DailyFlora data by clearing this site’s browser storage. Tutorial reset controls clear only tutorial keys. Turning off gesture control stops the active media stream. Because no real DailyFlora cloud account is currently created, there is no remote account record for DailyFlora to delete. Contact us if you believe information was received through another direct channel.

8. Children’s privacy

DailyFlora is not designed to knowingly collect personal information from children. A parent or guardian who believes a child has directly provided information to CALFN LAU should contact us.

9. Policy updates and contact

This policy must be revised before introducing real accounts, Supabase data storage, server image uploads, saved camera data, analytics, cookies, payments, email notifications, social integrations, public user pages or user publishing.

1. 处理的信息

DailyFlora 当前可能处理你在本机 MVP 表单填写的称呼与邮箱、花束收藏、界面语言、时钟与教程设置、日期与生成参数，以及你主动选择的参考图。当前公开站点未接入 DailyFlora 自有分析、广告追踪、支付或邮件通知系统。

2. 浏览器本机数据

姓名、邮箱、收藏、待机时钟设置、界面语言和教程选择保存在当前设备的 localStorage，不同步到 Supabase 或其他 DailyFlora 账户服务器。注册表单的密码不会被保存或发送。清除站点数据会删除这些记录。

收藏只保存日期、种子、主题、花材方案名称与保存时间等元数据，不保存服务器端 3D 场景副本。

3. 参考图与私人花束预览

选择参考图后，FileReader 在当前浏览器标签内读取文件，并用临时 Canvas 小图计算平均色彩、匹配主题方向。图片只在当前会话中本地显示，不上传 DailyFlora 服务器，也不写入 localStorage。收藏专属花束时只保存花束元数据，不包含源图片。

4. 摄像头与手势控制

只有你主动开启手势控制并启动摄像头后，DailyFlora 才请求摄像头权限；你可以随时关闭。MediaPipe Tasks Vision 在浏览器内分析实时帧，估计手部关键点和手势。

  • 不请求麦克风。
  • 不上传摄像头画面或手部图像。
  • 不保存视频、截图或手部图像。
  • 停止控制或页面卸载时会停止视频轨道。
  • 权限提示、指示灯和授权历史仍由浏览器与系统管理。

5. 分享与可能公开的信息

分享链接可能包含日期、种子、主题或画质参数，获得链接的人可以看到这些参数。当前本机账户信息与收藏不会自动加入分享链接，公开用户主页与用户发布尚未开放。

6. 第三方技术与服务

Three.js 用于 3D 渲染，MediaPipe Tasks Vision 用于浏览器内手势识别。站点可能由 GitHub Pages、Vercel 或其他配置的静态托管服务提供，它们可能依各自基础设施政策处理 IP、请求时间、浏览器标识等普通网络信息。DailyFlora 当前不设置营销 Cookie，也未加入第一方分析 SDK。

7. 数据删除与保留

清除本网站的浏览器存储即可删除本机 DailyFlora 数据；教程恢复按钮只清除教程键。关闭手势控制会停止媒体流。由于尚未创建真实云端账户，当前没有 DailyFlora 远程账户记录可删除。

8. 儿童隐私

DailyFlora 不以主动收集儿童个人信息为目的。监护人如认为儿童通过其他直接渠道提供了信息，请联系我们。

9. 政策更新与联系

接入真实账户、Supabase、服务器图片上传、摄像头数据保存、分析工具、Cookie、支付、邮件通知、社交平台、公开用户页或用户发布前，必须同步更新本政策。
