2026-06-25
0.12.x路由基础
foundation

MVP 路由、日期、镜头和精度语义

建立首页、日期参数、镜头路线和 render/density 的基本入口。用户可以从首页进入每日花束，再通过 URL 或界面切换日期、镜头和显示精度。

  • 每日花束：/?date=YYYY-MM-DD
  • 高精度验收：?render=high&density=high
2026-06-26
0.13.x花材库
shape vocabulary

Primitive Lab 与核心抽象词表

形成 16 类核心抽象目标形态。这里的 16 是一层词表，不是全部花型数量；后来新增 25 种偏写实花型、H01 和 C01 后，完整审核库存变成 43 条。

开发入口：Primitive Lab、偏写实花型 LAB、43 项验收页。

2026-07-03
0.14.0公开结构
public routes

公开网站与开发目录成形

加入 About、Bouquet Shop、Member、Downloads、Special Bouquet、内部开发组目录和 mock 管理页面。之后用户侧与内部侧开始有明确边界，旧 docs 管理页只作为历史 mock。

正式用户入口：/、/about/、/member/、/downloads/、/how-to-use/。

2026-07-20
0.16 / 0.71GUI v1
GUI + Clock UI

GUI v1、VIEW 菜单和空闲时钟首次进入实现线

黑色空间、左下花名、右上 INDEX、右下 VIEW、七语言选择器和反向括号动效进入主 GUI。Clock UI 以空闲时钟模式加入：时间、日期和名言在玻璃叠层中显示，设置留在 VIEW 菜单。

引导入口：用户从首页的 INDEX 进入说明和页面导航，从 VIEW 进入日期、精度、Clock mode 和手势设置。

2026-07-22—24
0.71手势控制
gesture control

浏览器手势从实验页进入可用控制

07-22 建立隔离的浏览器手势预览；07-23 完成左右手通用、掌形总开关和停止手势；07-24 合并到浏览器控制线并标记 GUI/手势控制发布批准。普通首页按需加载，用户从 VIEW 菜单打开。

  • 测试入口：?hand-control=1
  • 用户说明：/how-to-use/ 的完整手势表、摄像头边界和全屏说明
  • 实际功能：缩放、XY 构图移动、半合掌旋转、双手 spread、镜头/沉浸模式切换
2026-07-27
0.71 / 0.72Clock polish
clock behavior

Clock UI 自动隐藏、镜头让位和手动边界

修复时钟模式自动隐藏并恢复生产首页的时钟 chrome；花束在时钟出现前向左让位，VIEW 在时钟模式仍可打开。手动或自动 Clock overlay 只显示时间、日期和名言，不把设置按钮塞进叠层。

2026-08-03—14
0.72.0正式网页线
formal release

用户引导、法律页、Member 和正式 Admin

0.72 正式网页线统一首页、注册、登录、个人花园、公开说明和 Downloads 的导航；/how-to-use/ 补回手势表、Fullscreen 快捷键和 Clock mode 真实说明；正式 /admin/ 接入 Beta 账户后台。

这一步把“开发页有功能”变成“用户能知道去哪里”：普通用户走公开导航，已登录用户走 Member，管理员走 Admin；开发 LAB 从 Admin 的开发工作台进入。

2026-08-16
0.73.0整合候选
flower acceptance

0.15 已确认花型/叶片门禁定向整合

把 R01-R16、C01 和三组已通过花叶关系同步到正式源头；H01 与 01 盘状花保留 SciFi-only，08/09/10 不采用，13/14 先修显示 bug。花、茎、叶继续共享 PlantStemInstance，未确认叶片不自动生成。

完整库存显示为 16 核心抽象 + 25 写实 + H01 + C01 = 43 条审核记录；这次不将 0.15 的无关 GUI、账号或法律页面改动整体带入。

How users are guided

网站路由与引导

用户不需要知道内部 LAB 文件名。公开页面负责解释和使用，Admin 负责权限后的内部工作台，直接 docs 链接只作为开发验收快捷入口。

Home /
今天的花束→INDEX
了解产品、How to use、Member、Downloads→VIEW
日期、镜头、精度、Clock、手势→Member /
收藏、生成记录、账户
公开首页/

每日花束、GUI、INDEX、VIEW；普通用户从这里开始。

 使用说明/how-to-use/

手势表、Clock mode、Fullscreen、精度/密度与操作边界。

 个人花园/member/

注册后进入收藏、生成记录和账户工作台；/signup/ 是兼容入口。

 多端下载/downloads/

公开下载与平台说明，不从这里进入开发工具。

 正式 Admin/admin/

Beta 权限后台；开发工作台已并入此页面，账户数据与 LAB 入口分区。

 开发组目录/docs/dev-index.html

内部快捷目录；可从 Admin 进入，保留直接打开 LAB 的便利。

Admin → Developer workspace

开发工作台入口

正式 Admin 不再只有账户和任务列表。开发工作台是同一 Admin 页面内的内部导航层，不读取用户数据，也不把旧的静态 mock 当成正式后台。

审美门禁 Dashboard

43 项审核库存、R01-R16、C01、SciFi-only、叶片门禁。

 花型系统验收

逐项通过/不通过/待定；点击对应模型后自动定位。

 花叶搭配 LAB

当前三组已通过关系；未来继续增加，不用通用叶片补位。

 Primitive Lab

34 项共享画布：16 核心抽象、R01-R16、H01、C01。

 Realistic Flower LAB

25 种写实花型总览，支持单项 query 定位。

 固定花束样例

实际运行页面的日期、seed、主题和 flowerPlan 检查入口。
